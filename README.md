# LoudLlama Add-ons

A Home Assistant add-on repository. Add it once in Home Assistant to install its add-ons and get update notifications (and optional auto-update) straight from Home Assistant going forward — see "Installation" below for why that matters.

## Add this repository to Home Assistant

1. **Settings → Add-ons → Add-on Store → ⋮ (menu, top right) → Repositories**.
2. Paste in this repository's URL: `https://github.com/loudllama/loudllama-dashboard`
3. **Add**, then close the dialog — the add-on(s) below now show up in the store.

## Add-ons in this repository

- **[LoudLlama Dashboard](loudllama_dashboard/README.md)** — build your own freely customizable, iPad-style dashboard in Home Assistant, with movable widgets and a built-in widget store so you only run the widgets you actually use.

See that add-on's own `README.md` and `DOCS.md` (linked above) for what it does, how to install and configure it, and how updates work.
